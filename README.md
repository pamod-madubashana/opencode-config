# OpenCode MCP Servers

MCP server configurations for OpenCode.

## Servers

| Server | Description | Guide |
|--------|-------------|-------|
| GitHub | GitHub API integration | [mcp/github.md](mcp/github.md) |
| Playwright | Browser automation | [mcp/playwright.md](mcp/playwright.md) |

## Quick Start

1. Set up environment variables (see server guides)
2. Copy the MCP config to your `opencode.json`
3. Restart OpenCode

## Verify

```bash
opencode mcp list
```
